📘 Material Icons 使用说明

1. 本质：图标其实是"文字"

Material Icons 并不是图片（如 .jpg 或 .png），而是一种特殊的字体（Web Font）。

就像 Times New Roman 字体里包含 A, B, C 这些形状一样，Material Icons 字体里包含撤销箭头、加粗B、垃圾桶等图标形状。

2. 如何使用？

在你的 HTML 代码中：

<span class="material-icons">undo</span>

这对浏览器来说包含两层指令：

  • 指令 A（内容）：请显示 "undo" 这个字符（或者对应的一串代码）
  • 指令 B（样式）：请用 material-icons 这个专用字体来渲染它

3. 必须引入字体链接

如果 HTML <head> 里没有引入该字体的下载链接，浏览器会想："你让我用 Material Icons 字体，但我不知道去哪里下载这个字体包？"

因此，必须在 <head> 中添加：

<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">

这样浏览器才能从 Google Fonts 下载 Material Icons 字体文件，正确显示图标。

4. 常见问题

  • 如果图标显示为空白或显示文字（如 "undo"），说明字体链接没有正确引入
  • 如果网络环境无法访问 Google Fonts，可以考虑使用本地字体文件或 CDN 镜像
  • 使用时确保 class 名称为 "material-icons"，且内容为有效的图标名称
