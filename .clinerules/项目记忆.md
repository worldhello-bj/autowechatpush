# 微信AI发布助手 - 项目记忆（基于实际功能）

## 项目概述

**项目名称**: 微信AI发布助手 (WeChat AI Publisher)
**版本**: 前端 1.3.0 / 后端 1.0.0
**技术栈**: 
- 前端: React 18 + TypeScript + Vite + Tailwind CSS + Electron
- 后端: Node.js + Express + TypeScript
**项目类型**: 全栈应用（前端 + 后端 + Electron桌面应用）
**核心目标**: 通过AI辅助快速生成和发布微信公众号文章

## 实际系统架构

### 整体架构
```
用户界面 (React前端) ↔ RESTful API (Express后端) ↔ AI服务提供商
       ↓                              ↓
Electron桌面应用               文件存储 (JSON) + 内存存储
       ↓
微信公众号API
```

### 前后端分离架构
- **前端**: 单页应用，负责用户交互和内容编辑
- **后端**: RESTful API服务，处理业务逻辑和AI集成
- **通信**: HTTP/HTTPS + SSE流式响应
- **数据存储**: 文件系统存储（JSON格式）+ 内存存储（用户、配额等）

## 实际核心功能模块

### 1. 认证系统（实际实现）
- **用户管理**: 注册、登录、JWT令牌管理（基于文件存储）
- **角色系统**: 普通用户、管理员（后端实现）
- **配额管理**: 基于使用次数的配额系统（文件存储）
- **安全特性**: 密码哈希、令牌刷新、会话管理

### 2. AI文章生成系统（实际实现）
- **多AI提供商**: DeepSeek、通义千问（Qwen）
- **双AI模式**: 内容生成 + 设计美化协作（前端实现）
- **格式化模式**: 现有文本转换为精美排版
- **流式响应**: SSE技术实现实时生成体验
- **自动回退**: 主提供商失败时自动切换（后端实现）
- **AI密钥池**: 后端统一管理API密钥，前端不接触密钥
- **Prompt管理系统**: 后端统一管理所有prompt配置，支持用户自定义prompt

### 3. Prompt管理系统（新增）
- **集中配置**: 所有prompt在后端统一管理（systemPrompt、generationPrompt、formattingPrompt等）
- **用户自定义**: 支持userprompt参数，允许用户个性化AI行为
- **安全过滤**: 对用户输入的prompt进行验证和过滤，防止恶意内容
- **多轮对话**: 支持多轮对话prompt配置，实现复杂的AI协作工作流
- **实时更新**: 管理员可通过管理后台实时更新prompt，无需重启服务

### 4. 编辑器系统（实际实现）
- **富文本编辑器**: 基于contenteditable的HTML编辑器
- **区块系统**: 20+种文章区块类型（标题、段落、图片、卡片、表格、进度条等）
- **实时预览**: 手机模拟器实时预览
- **素材库**: 内置图片、视频、GIF、SVG素材（前端预设）
- **模板库**: 丰富的排版设计模板（前端实现）
- **个性化prompt**: 支持用户自定义prompt输入，个性化内容生成

### 5. 微信集成（实际实现）
- **草稿管理**: 保存到微信公众号草稿箱
- **图片上传**: 自动上传图片到微信服务器
- **文章发布**: 一键发布到微信公众号
- **API集成**: 微信开放平台API完整集成（前端直接调用）
- **配置管理**: 微信AppID和AppSecret由用户在前端本地存储，无系统级配置，增强安全性

### 6. 管理功能（实际实现）
- **用户管理**: 创建、更新、删除用户（后端API）
- **配额管理**: 调整用户配额计划（后端API）
- **系统监控**: 使用统计和性能监控（日志系统）
- **AI密钥管理**: 多API密钥池管理（后端统一管理）
- **Prompt管理**: 通过管理后台查看和编辑所有prompt配置

### 7. 辅助功能（实际实现）
- **文章导入**: 从微信公众号链接导入文章结构
- **图片拼接**: 多图拼接为长图功能
- **AI工具集**: 标题生成、摘要提取、关键词提取、内容润色等
- **设计模板**: 丰富的排版模板库

## 实际技术栈详解

### 前端技术栈
- **React 18**: 现代前端框架，支持并发特性
- **TypeScript**: 类型安全，提高代码质量
- **Vite**: 快速构建工具，支持热重载
- **Tailwind CSS**: 实用优先的CSS框架
- **Electron**: 跨平台桌面应用框架
- **状态管理**: React Hooks + Context API
- **路由**: React Router DOM
- **HTTP客户端**: 自定义API客户端

### 后端技术栈
- **Node.js**: JavaScript运行时环境
- **Express**: 轻量级Web应用框架
- **TypeScript**: 类型安全的服务器端开发
- **JWT**: JSON Web Token认证
- **SSE**: Server-Sent Events流式响应
- **文件存储**: JSON文件持久化（用户、配额、日志等）
- **安全中间件**: Helmet、CORS、速率限制
- **配置服务**: 专注于AI密钥和prompt管理，不包含微信配置（微信配置由前端本地存储）

### AI服务集成（实际）
- **DeepSeek API**: 文本生成和代码生成（函数调用）
- **通义千问API**: 文本生成和图片分析（DashScope）
- **API密钥管理**: 后端密钥池轮询使用，前端无密钥访问
- **函数调用**: 结构化数据提取（layout_article工具）
- **流式处理**: 实时内容生成（SSE）
- **Prompt集成**: 后端统一管理prompt，支持用户自定义和系统默认结合

## 实际数据流设计

### 文章生成流程（实际）
```
用户输入 → 前端验证 → 后端API → 配额检查 → Prompt构建 → AI服务调用
    ↓          ↓          ↓          ↓          ↓          ↓
主题/图片   输入验证   参数验证   配额验证   系统+用户prompt   API请求
    ↓          ↓          ↓          ↓          ↓          ↓
本地存储   错误处理   密钥池选择   使用记录   安全过滤   流式响应
    ↓          ↓          ↓          ↓          ↓          ↓
草稿保存   用户反馈   配额扣减   日志记录   变量替换   结果解析
    ↓          ↓          ↓          ↓          ↓          ↓
实时预览   错误提示   状态更新   监控数据   prompt日志   HTML转换
```

### 微信发布流程（实际）
```
文章内容 → HTML转换 → 图片上传 → 草稿保存 → 文章发布
    ↓          ↓          ↓          ↓          ↓
区块编辑   微信兼容   微信CDN   公众号API   发布确认
    ↓          ↓          ↓          ↓          ↓
实时预览   样式优化   链接替换   草稿ID     结果反馈
```

## 实际安全性和性能

### 安全措施（实际实现）
- **认证安全**: JWT令牌 + 刷新令牌机制
- **输入验证**: 前后端双重验证
- **XSS防护**: DOMPurify HTML净化
- **速率限制**: 防止API滥用（express-rate-limit）
- **CSP配置**: Content Security Policy（Helmet）
- **密钥管理**: API密钥池轮询使用，前端无密钥访问
- **Prompt安全**: 用户自定义prompt验证和过滤，防止恶意内容
- **微信配置安全**: 微信AppID和AppSecret由用户在前端本地存储，管理员无法查看或控制，增强隐私和安全性

### 性能优化（实际实现）
- **前端优化**: 代码分割、懒加载、图片优化
- **后端优化**: 内存缓存、流式响应、并发控制
- **网络优化**: HTTP/2、CDN加速、压缩传输
- **存储优化**: 防抖写入、原子操作、JSON序列化

## 实际已知问题和改进建议

### 当前限制（基于代码分析）
1. **存储限制**: 文件存储不适合大规模部署
2. **性能瓶颈**: 单进程架构，无负载均衡
3. **功能依赖**: 部分AI功能需要特定API密钥
4. **监控不足**: 缺乏详细的性能监控和告警
5. **图片分析/TTS**: 后端接口尚未完全实现

### 短期改进建议
1. **数据库迁移**: 迁移到PostgreSQL或MongoDB
2. **缓存集成**: 添加Redis缓存层
3. **监控增强**: 集成Prometheus和Grafana
4. **测试覆盖**: 增加单元测试和集成测试
5. **功能完善**: 实现图片分析和TTS后端接口

### 长期发展规划
1. **微服务架构**: 将系统拆分为独立服务
2. **消息队列**: 使用RabbitMQ处理异步任务
3. **容器编排**: Kubernetes集群部署
4. **多云支持**: 支持多个云服务提供商
5. **API开放**: 提供第三方开发者API

## 实际开发团队指南

### 新开发者入门
1. **环境搭建**: 安装Node.js 18+、Git、VSCode
2. **项目克隆**: `git clone https://github.com/worldhello-bj/autowechatpush.git`
3. **依赖安装**: `npm install` (前端) 和 `cd backend && npm install` (后端)
4. **环境配置**: 复制.env.example文件并配置AI密钥
5. **启动开发**: `npm run dev` (前端) 和 `npm run dev` (后端)
